# Power Bi Sales and Profit Dashboard
## Project Overview
This project analysis sales and profit data using Power Bi.
## Objectives
* Analyze total sales and total profit.
* compare sales performance across regions.
* Understand sales trends by order date.
* Identify business performance using  interactive visuals
##  Tools used
* Microsoft Power Bi
* Data Visualization
* Data Analysis
##  Dashboard Features
 * Total Sales KPI.
 * Total Profit KPI.
 * Sales by Region
 * Sales by Category
 *Data slicer for filtering data
## Key Learnings
* Creating Interactive dashboard
* Using slicers charts
* Analyzing sales and profit performnce
